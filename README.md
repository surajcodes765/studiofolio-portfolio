# StudioFolio — Creative Portfolio

## Project Overview
StudioFolio is a responsive portfolio website
for showcasing creative design services and projects.

## Features
- Responsive website layout
- Services section
- Six portfolio project cards
- Category-based project filtering
- Interactive testimonial carousel
- About and contact sections

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.

## Project Purpose
Created as an academic web development project.
The portfolio projects and testimonials are sample content.
